# Week 01 --- Python Foundations 🐍

## 90 Days of AI Agent Engineering

### Week 1 Focus

**Level:** Beginner

This week I went back to the Python foundations to strengthen my
understanding of the language I use in AI and backend development.

## What I Learned

-   Variables and data types
-   Collections: lists, dictionaries, tuples and sets
-   Conditions (`if`, `elif`, `else`)
-   Loops (`for` and `while`)
-   Functions
-   Modules
-   Exception handling
-   Working with files
-   JSON

## What I Built

### 🎮 Rock Paper Scissors

I built a simple Rock Paper Scissors command-line game.

This project helped me practise:

-   User input
-   Conditions
-   Functions
-   Lists
-   The `random` module
-   Debugging Python errors

One important lesson was understanding that getting an error is part of
learning. Instead of only trying to make the program work, I spent time
understanding why it failed and how the fix worked.

### ✅ CLI Task Manager

I also built a command-line Task Manager.

The first version allows a user to:

-   Add a task
-   View tasks
-   Exit the program
-   Handle an invalid menu choice

This project helped me understand how Python concepts work together in
one program, especially lists, loops, conditions, functions and user
input.

## What I Learned From Week 1

My biggest goal with this challenge is not to rush through tutorials or
let AI build everything for me.

My learning process is:

> **Learn → Build → Break → Debug → Understand → Document**

Even though I already work in AI Engineering, going back to the
fundamentals is helping me understand Python more deeply and become more
confident explaining the code I write.
